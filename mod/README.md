# Azeroth Survivors mod

Неофициальный мод для **Azeroth Survivors под Windows x64**: общий прогресс
классов, дополнительные предметы и задания, PvP по числу убийств и кооп на двоих
с общими врагами.

Мод собирает `AzerothSurvivors-52.exe` из установленного у тебя оригинала.
Официальный `AzerothSurvivors.exe` сохраняется без изменений. Игровые файлы
и сохранения в репозиторий не входят.

## Возможности

- **52 очка талантов:** каждый класс получает одно начальное очко; пороги опыта
  остаются прежними. Опыт талантов и открытые зоны выравниваются между классами
  по лучшему достигнутому результату. Распределение талантов остаётся отдельным
  для каждого класса.
- **Подбор опыта:** заметный полёт частиц и магнит, который направляет их
  к текущему положению героя.
- **Два дополнительных кольца:** Кольцо сложности и Кольцо шипов. Двойной клик
  по предмету в кодексе запрещает его выпадение; запускатель сохраняет запреты
  между запусками.
- **Задания «Разведка»:** подойди к духу с `!`, обойди пять точек за 2:30
  и получи штатный выбор предмета. Первый дух появляется через две минуты
  игрового времени; следующий — через три минуты после завершения задания.
- **Русская локализация:** дополнения к встроенным текстам, включая новые
  предметы и непереведённые таланты.
- **Онлайн:** отдельный профиль матча, окно напарника, страница наблюдения
  и перенос заработанного прогресса обратно в основное сохранение.
- **Восстановление адресов после обновлений:** поиск по сигнатурам, проверка
  инструкций и полей структур, автоматический отчёт о совместимости.

## Установка и запуск

### Лаунчер (рекомендуется)

Скачай один файл **Azeroth Launcher.exe** со [страницы релизов](https://github.com/VladXon/azeroth-survivors-mod-releases/releases/latest)
и запусти его. Python, WinRAR и 7-Zip не нужны.

1. **Первый запуск.** Выбери папку и нажми «Установить». Лаунчер скачает
   оригинальную игру с официального сайта [wow.aethus.pl](https://wow.aethus.pl/)
   (около 720 МБ, после распаковки 1,8 ГБ, с докачкой при обрыве), проверит архив, распакует его через
   встроенный 7-Zip и установит мод с GitHub. Если игра уже установлена,
   выбери «Указать папку с игрой»: старый пакет с BAT-файлами лаунчер заменит
   сам, прежний мод останется в `.azs-mod-backup`.
2. **Играть.** Вкладки «Обычная игра», «Кооп» и «PvP» вверху, одна большая
   кнопка внизу. Регистрация ника, поиск напарника, приглашения и матч —
   прямо в окне лаунчера.
3. **Обновления.** При каждом запуске и раз в 10 минут лаунчер проверяет
   GitHub. Новую версию мода он ставит перед запуском игры, о выходе версии во
   время работы сообщает плашкой «Обновить сейчас». Свой EXE он обновляет сам.
   Без интернета работает уже установленная версия.

В «Настройках» — папка игры, журнал, версии и запуск оригинальной игры для
её собственного обновления. Окну нужен Microsoft Edge WebView2 Runtime (есть в
Windows 11 и обновлённой Windows 10); если его нет, лаунчер откроет страницу
загрузки. Журнал: `%LOCALAPPDATA%\AzerothSurvivorsMod\launcher.log`.

### Из исходников

Нужны Git, **64-битный Python 3.11 или новее** с Tkinter и установленная игра.
Закрой игру перед первым запуском мода. В PowerShell перейди в её каталог:

```powershell
Set-Location 'H:\Games\AzerothSurvivors'
git clone https://github.com/Anfi1/azeroth-survivors-mod.git mod
python -m pip install -r .\mod\requirements.txt
```

Обычная игра:

```powershell
pythonw .\mod\launcher.pyw
```

Окно PvP и коопа:

```powershell
pythonw .\mod\launcher.pyw --pvp
```

Запускатель проверит сборку, при необходимости пересоберёт модифицированный
EXE, синхронизирует общий прогресс и скопирует переводы. В обычном режиме он
запустит игру; в онлайн-режиме игра запускается из окна матча.

Для ярлыка укажи путь к `pythonw.exe`, в аргументах — полный путь
к `mod\launcher.pyw` и, для онлайна, `--pvp`. Рабочая папка — каталог игры.

### Из готового архива (прежний способ)

Архив, собранный через [tools/build_release.py](https://github.com/Anfi1/azeroth-survivors-mod/blob/main/tools/build_release.py), содержит
собственную среду выполнения: отдельная установка Python не требуется.
Распакуй его рядом с оригинальным EXE и запускай:

- `Azeroth Survivors MODDED.bat` — обычная игра;
- `Azeroth Survivors MODDED Онлайн.bat` — PvP и кооп.

Прямой запуск `AzerothSurvivors-52.exe` пропускает проверку обновлений,
синхронизацию основного сохранения и сохранение запретов предметов. Для обычной
игры используй запускатель.

## PvP: гонка по убийствам

1. Зарегистрируй ник в онлайн-окне и вызови другого игрока по нику либо прими
   приглашение. Ник: 3–16 латинских букв, цифр или `_`.
2. После принятия сервер выбирает одну из пяти последних зон: `sm`, `av`,
   `brm`, `aq`, `naxx`. Открытие зоны в основном сохранении не требуется.
3. Клиент создаёт профиль матча с выбранной зоной и настройками. По умолчанию
   плотность и здоровье врагов — **125%**, урон и скорость — **100%**.
4. Начни забег в течение трёх минут. Убийства учитываются до появления
   последнего босса зоны; серверный предел забега — 40 минут, бюджет пауз —
   пять минут на игрока.
5. Побеждает игрок с большим числом убийств. Равный результат даёт ничью;
   рейтинг рассчитывается по Elo.

Проценты и лимиты задаются сервером. Значения выше соответствуют
[server/wrangler.toml](https://github.com/Anfi1/azeroth-survivors-mod/blob/main/server/wrangler.toml).

## Кооп на двоих

Найди напарника в онлайн-окне, выбери зону и отправь приглашение. **Выбрать
можно любую из 12 зон**, даже если она ещё закрыта в основном сохранении.
Меню изначально предлагает самую дальнюю зону, открытую обоими игроками.
На сервере по умолчанию плотность и здоровье врагов — **250%**, урон и скорость — **100%**.
Текущий адрес: `https://azeroth-pvp.azeroth-pvp-server.workers.dev`.
После перехода со старого сервера зарегистрируй ник заново: сетевые аккаунты
и рейтинг хранятся отдельно. Сохранения игры и заработанный прогресс остаются
на компьютере. Если прежний токен не принят, окно само предложит регистрацию;
старый `pvp.json` остаётся на месте до её успешного завершения, затем — в `.bak`.

В совместимой сборке оба игрока видят героя напарника, рамку группы, его
положение на миникарте и общую таблицу врагов. Врагом управляет одна сторона;
позиции, урон, здоровье боссов и награды синхронизируются. Добыча и опыт
выдаются каждому игроку его игрой. Если обе сборки поддерживают синхронизацию
часов, часы гостя следуют за часами хоста.

Для общих врагов нужны совместимые версии игры, мода и сервер с `relay: 3`.
При несовместимости отдельные функции могут отключаться: наличие онлайн-окна
само по себе не означает, что общие враги включены.

При потере связи игра постепенно возвращается к самостоятельному управлению
врагами и спавном. Смерть одного участника завершает оба забега поражением;
выход участника оставляет напарнику возможность продолжить одному. В коопе
нет рейтинга и общего лимита длительности: сервер завершает участие игрока
после десяти минут отсутствия активности.

### Локальная сеть (Radmin VPN, LAN)

Вместо интернет-сервера можно играть через свой компьютер: в лаунчере на вкладке «Кооп»
или «PvP» выбери «Локальная сеть». Это удобно с [Radmin VPN](https://www.radmin-vpn.com/)
(у всех одна сеть с адресами `26.x.x.x`) или в одной домашней сети.

1. Один игрок выбирает **«Я создаю игру»** и нажимает «Войти в онлайн». Лаунчер
   показывает его адреса (адрес Radmin выделен) и держит игру у себя (`lan_server.py`, порт 47630).
   Если Windows спросит про брандмауэр, отметь частные и общественные сети.
2. Остальные выбирают **«Подключаюсь к другу»**, жмут «Найти в сети» или вводят адрес хоста,
   затем «Войти в онлайн». Дальше всё как обычно: ник, приглашение, матч.

Ник в локальной сети регистрируется отдельно от интернет-сервера: аккаунт сервера мода
сохраняется в `pvp.json`. Список игроков хоста хранится в `%APPDATA%\wenilla-rogue\lan-hub.json`, а матчи — только пока
открыт лаунчер хоста. В локальной сети кадры идут 30 раз в секунду (через интернет — до 20) и хаб
пересылает их все без ограничений сервера. Хост выбирает сложность кооп: 150%, 250% (как на сервере)
или 400% врагов и их здоровья. Сейчас в матче два игрока: протокол хаба рассчитан на большее,
но игра пока показывает одного напарника.

### Качество связи

В окне матча лаунчер показывает пинг до сервера (или до хоста в локальной сети), сколько кадров
напарника приходит в секунду и насколько позже реального он показан. Если кадр опаздывает,
герой напарника ещё до 0,15 с идёт по последнему направлению вместо того, чтобы замереть.
Удары напарника, которые не поместились в очередь игры, ждут следующего тика и не теряются.

### Защита во время выбора награды

Функция включается после согласования поддержки между обновлёнными клиентами.

- Пока открыт выбор уровня, сундука или стража, исходящий урон выбирающего
  игрока отключён. Перезарядки продолжаются. Меню Esc защиту не включает.
- Игрок **полностью неуязвим первые 5 секунд каждого выбора**. После пяти
  секунд иммунитет заканчивается, даже если выбор ещё открыт.
- Напарник получает «Прикрытие»: **+50% исходящего урона и −20% входящего**
  на первые четыре секунды выбора. Для непрерывной цепочки «Прикрытия» действует
  предел восемь секунд; он сбрасывается после пяти секунд без открытого выбора.
- Обычные общие враги переключаются на прикрывающего в пределах 50 ярдов,
  иначе останавливаются. Владельцы боссов и стражей на время защиты сохраняются.
- Если оба выбирают награду, «Прикрытие» отключается, цели сохраняются,
  а каждый получает свои 5 секунд неуязвимости. Закрытие выбора,
  который пересекался с выбором напарника, даёт ещё секунду снижения урона на 90%.
- После закрытия выбора обычные живые враги ближе **12 ярдов** от героя
  сдвигаются на **5 ярдов наружу от своего текущего положения**. Волна срабатывает один раз за закрытие;
  боссы, стражи и их особые помощники исключены. Для общих врагов хост передаёт
  свои перемещения, а гость применяет волну к врагам под своим управлением.

Фильтр визуальных эффектов удаляет проверенные пакеты `SMSG_SPELL_GO`
локального героя. Касты призванных существ, начало заклинаний и уже видимые
снаряды скрываются не полностью. Нативные хуки проверены офлайн в эмуляторе;
полная проверка этой механики с двумя игроками в игре остаётся отдельным этапом.

## Сохранения и прогресс матча

Основной каталог по умолчанию: `%APPDATA%\wenilla-rogue`.

| Файл или каталог | Назначение |
|---|---|
| `characters.txt` | Основное сохранение |
| `pvp\characters.txt` | Отдельное сохранение текущего PvP/кооп-матча |
| `pvp.json` и `pvp.json.bak` | Ник, токен аккаунта и состояние онлайн-клиента |
| `mod_bans.json` | Запреты дополнительных предметов по их ID |
| `pvp-log.txt` | Журнал онлайн-клиента |
| `characters.before-share.txt` | Первая резервная копия перед изменением общего прогресса |
| `characters.before-pvp-<matchId>.txt` | Копия основного сохранения перед слиянием; сохраняются пять последних |

После окончания матча и закрытия игры клиент переносит в основное сохранение
заработанный опыт талантов, предметы, записи кодекса, статистику и достижения.
Распределённые в матче таланты переносятся, если основное распределение этого
класса с начала матча не менялось. Выбор персонажа, экипировка и внешность
основного профиля сохраняются.

В PvP открытие зон не переносится. В коопе засчитываются победы в зонах,
которые основное сохранение уже позволяло проходить, с открытием следующей.
Прохождение заранее закрытой поздней зоны само по себе не открывает её
в основном профиле.

Дождись закрытия матчевой игры и слияния прогресса, прежде чем снова играть
основным профилем. В онлайн-окне есть кнопка «Вернуться в обычную игру».

## Обновления игры и мода

1. Закрой модифицированную игру.
2. Запусти официальный `AzerothSurvivors.exe`, дай ему обновиться и закрой.
3. Запусти мод через обычный запускатель.

Патчер повторно определит адреса из нового оригинала. После успешной сборки
рядом с EXE появятся `.feed.json`, `.offsets.json` и `.source-sha256`.
Проверка актуальности учитывает оригинал, исходники патчей и resolver,
целостность модифицированного EXE и сопутствующие данные.

Автовосстановление поддерживает проверенные сигнатуры и варианты инструкций.
Существенная смена алгоритма или соглашения о вызовах может потребовать
адаптации патча. При отказе обязательной проверки новый EXE не подменяет
предыдущую сборку; для необязательных функций выводится явное отключение.

Для обновления исходников закрой игру и обнови свою копию репозитория,
сохранив собственные изменения. Затем снова используй запускатель.

## Если что-то не работает

Переносимая версия проверяет последний стабильный выпуск из
[публичного репозитория релизов](https://github.com/VladXon/azeroth-survivors-mod-releases/releases/latest) перед запуском
игры. Новый ZIP проверяется по SHA-256, устанавливается после закрытия старого
запускателя, затем открывается тот же обычный/онлайн-режим. При недоступном
GitHub запускается установленная версия. Новый выпуск с этой функцией нужно
один раз установить вручную; последующие выпуски будут обновляться автоматически.

Свой `pvp_server.txt` и `updater.json` переносятся в новую папку. Предыдущая
версия сохраняется в `.azs-mod-backup` рядом с игрой; при ошибке установки
восстанавливается автоматически. Сохранения и аккаунт находятся отдельно.
Журнал обновления: `%LOCALAPPDATA%\AzerothSurvivorsMod\updater.log`.
Для отключения создай `mod/updater.json` с содержимым `{"enabled": false}`.
Рабочие копии с `.git` автообновление пропускает, чтобы сохранить локальные правки.

| Симптом | Что проверить |
|---|---|
| Запускатель сообщает, что игра уже открыта | Закрой обычный и модифицированный EXE; запускатель меняет сохранение перед стартом |
| `the game changed, patch not applied` | Сохрани сообщение и SHA-256 оригинала; запусти проверку совместимости из руководства разработчика |
| Онлайн не соединяется | Адрес в `mod/pvp_server.txt` или переопределение `AZS_PVP_SERVER`, доступность настроенного сервера и `pvp-log.txt` |
| Напарник виден, но враги раздельные | Совместимость сборок, серверный `relay: 3` и отключённые функции в отчёте сборки |
| Запреты предметов не сохраняются | Запуск через `launcher.pyw`/BAT и доступность `mod_bans.json` |
| Долго висит подготовка мода | Обнови мод: исправлен медленный поиск квестового патча. В новом запускателе виден конкретный этап; последние этапы и ошибки находятся в `%LOCALAPPDATA%\AzerothSurvivorsMod\launcher.log` |
| Окно Python быстро закрывается | Запусти `python .\mod\launcher.pyw` из PowerShell и сохрани сообщение об ошибке |

Содержимое `pvp.json` содержит токен аккаунта. Перед публикацией диагностики
убери токен и личные данные.
