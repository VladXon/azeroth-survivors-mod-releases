# Azeroth Survivors — релизы мода

Готовый мод для Azeroth Survivors под Windows 10/11 x64. Отдельный Python не нужен.

**[Скачать последний релиз](https://github.com/VladXon/azeroth-survivors-mod-releases/releases/latest)** — выбери файл `AzerothSurvivors-mod-…-game-dc104533.zip` в разделе Assets.

## Установка и обновление

1. Закрой игру и окно онлайна. После матча дождись переноса прогресса.
2. Скопируй `%APPDATA%\wenilla-rogue` в резервное место. При обновлении переименуй старую папку `mod` в `mod-old`.
3. Распакуй содержимое ZIP в папку с оригинальным `AzerothSurvivors.exe`. Папку `mod/runtime` переноси целиком. Подтверди замену BAT-файлов.
4. Для обычной игры запусти `Azeroth Survivors MODDED.bat`, для коопа и PvP — `Azeroth Survivors MODDED Онлайн.bat`.

Запускатель соберёт отдельный `AzerothSurvivors-52.exe`; оригинальный EXE сохраняется. Сохранения и сетевой аккаунт находятся вне папки мода — не заменяй их чужими файлами.

Этот выпуск с автообновлением установи вручную один раз. Следующие стабильные релизы проверяются и устанавливаются перед запуском. При недоступном GitHub работает установленная версия. Предыдущий мод остаётся в `.azs-mod-backup`. Для отключения создай `mod/updater.json` с содержимым `{"enabled":false}`.

## Кооп и баланс

- Неуязвимость длится первые **5 секунд каждого выбора** награды.
- После выбора обычные враги в радиусе 12 ярдов сдвигаются **на 5 ярдов наружу**. Боссы, стражи и их особые помощники исключены.
- Кооп: **250% врагов / 250% здоровья**, урон и скорость — 100%.
- Сервер: `https://azeroth-pvp.azeroth-pvp-server.workers.dev`.

Обновите обоих игроков. На новом сервере ник нужно зарегистрировать заново: прежние сетевые аккаунты и рейтинг не переносятся. Сохранения игры остаются на компьютере. Собственный адрес сервера можно задать в `mod/pvp_server.txt`; старый официальный адрес автоматически заменяется новым.

## Совместимость и диагностика

Проверенная игра: Windows x64, **сборка dc104533** — первые восемь символов SHA-256 оригинального EXE. Полный хеш: `dc10453398ceb398076f6d3b6ac7859470de2ff7ccd68ac1d00a02f9f1e5209a`. Числовой номер версии в EXE отсутствует; для каждой публикации версия мода указана в названии релиза и внутри ZIP.

Ошибки запуска: `%LOCALAPPDATA%\AzerothSurvivorsMod\launcher.log`; обновления: `updater.log` в той же папке. Правила мода и подробная инструкция входят в ZIP. Игровые файлы, сохранения и токены в релизы не входят. Пакет подготовлен с помощью Codex; лицензии компонентов находятся в `mod/licenses/`.
