# Azeroth Survivors — лаунчер мода

Неофициальный мод для Azeroth Survivors под **Windows 10/11 x64**. Всё ставится и запускается
через один файл — **Azeroth Launcher.exe**. Python, WinRAR и 7-Zip не нужны.

**[Скачать лаунчер](https://github.com/VladXon/azeroth-survivors-mod-releases/releases/latest)** —
в разделе Assets файл `Azeroth.Launcher.exe` (GitHub заменяет пробел в имени на точку).

## Как начать

1. Положи `Azeroth.Launcher.exe` в любую папку и запусти.
2. **Игры ещё нет:** выбери папку и нажми **«Установить»**. Лаунчер скачает оригинальную игру
   с официального сайта [wow.aethus.pl](https://wow.aethus.pl/) (около 720 МБ, после обрыва
   связи загрузка продолжится), проверит архив, распакует его и поставит мод.
3. **Игра уже есть:** нажми «Указать папку с игрой» и выбери папку с `AzerothSurvivors.exe`.
4. Вверху выбери режим — **Обычная игра**, **Кооп** или **PvP** — и нажми большую кнопку внизу.
   Ник, поиск друга, приглашения и ход матча — прямо в окне лаунчера.

## Обновления

Лаунчер проверяет GitHub при запуске и каждые 10 минут. Новая версия мода ставится перед
игрой; если она вышла, пока лаунчер открыт, появится плашка **«Обновить сейчас»**. Себя лаунчер
обновляет сам. Без интернета работает уже установленная версия. Файлы мода берутся из папки
`mod/` этого репозитория по тегу версии и сверяются с SHA-256 из `latest.json`.

**Переход с прежнего пакета (ZIP с BAT-файлами, версии до 2026.10.23.4):** его встроенное
обновление новые выпуски не увидит. Скачай лаунчер один раз и укажи папку с игрой — он поставит
новый мод, а старые BAT-файлы и `mod/runtime` перенесёт в `.azs-mod-backup`.

## Кооп и баланс

- Кооп: **250% врагов / 250% здоровья**, урон и скорость — 100%. Общие враги и боссы.
- Первые **5 секунд каждого выбора** награды — неуязвимость; после выбора обычные враги
  в радиусе 12 ярдов сдвигаются на 5 ярдов наружу.
- Сервер: `https://azeroth-pvp.azeroth-pvp-server.workers.dev`. Обоим игрокам нужна одна версия мода.

## Безопасность и данные

- Оригинальный `AzerothSurvivors.exe` не меняется: мод собирает рядом `AzerothSurvivors-52.exe`.
- Сохранения и сетевой аккаунт — в `%APPDATA%\wenilla-rogue`; лаунчер их не удаляет и не заменяет.
- Игра скачивается напрямую с сайта разработчика; в этом репозитории игровых файлов нет.
  Разработчик игры не публикует контрольную сумму архива: лаунчер проверяет CRC архива,
  размер и состав, а SHA-256 архива и EXE записывает в `.azs-game.json` в папке игры.
- Журнал: `%LOCALAPPDATA%\AzerothSurvivorsMod\launcher.log` (кнопка «Журнал лаунчера» в настройках).

## Требования

Windows 10/11 x64 и Microsoft Edge WebView2 Runtime (есть в Windows 11 и обновлённой Windows 10;
если его нет, лаунчер откроет страницу загрузки). Около 2,6 ГБ свободного места для установки игры.
